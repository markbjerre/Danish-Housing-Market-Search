# Danish Housing Market Search

Production-ready system for importing and analyzing Danish property data from the Boligsiden API.

**228,594 properties** | **3,623 active listings** | **36 municipalities** within 60km of Copenhagen

## Quick Start

```bash
# Setup
python -m venv venv
.\venv\Scripts\activate   # Windows
pip install -r requirements.txt

# Start web app
cd webapp && python app.py
# Visit: http://127.0.0.1:5000
```
